# 5. Production Lifecycle for a Brand-New Project

This diagram shows how the system guarantees 0-second UI blocking for the Sales Manager while safely running the heavy 45-minute CAD drawing extraction in the background, followed by instant 1-millisecond summary enrichment.

```mermaid
sequenceDiagram
    autonumber
    actor Customer as Customer / General Contractor
    participant Pass2 as Phase 1: Pass 2 Classifier
    participant UI as Estimator / Sales Manager UI
    participant Stage0 as Background Extraction Worker
    participant Enricher as Phase 2: Summary Enricher

    Customer->>Pass2: Sends new RFQ email + 50-page PDF
    Pass2->>UI: Phase 1 Summary generated in ~2 seconds!<br/>(Sales Manager sees lead immediately in Drafts)
    
    rect rgb(240, 240, 240)
    Note over Stage0: BACKGROUND ASYNC WORKER (~45-60 mins)
    Pass2->>Stage0: Dispatches drawings to Azure Service Bus Queue
    Stage0->>Stage0: Renders 200 DPI sheets, reads dimensions, rescues tiles, reconciles units
    end

    Stage0->>Enricher: Hands over verified CAD extraction JSON
    Enricher->>Enricher: Enriches summary with verified dimensions & frame series in 1ms!
    Enricher->>UI: Updates Project with Enriched Summary & Reasoning<br/>(Estimator sees exact units & specs)
```
