# 4. Pipeline Journey & Prompt Mapping (Who Calls Which Prompt?)

This sequence diagram shows the step-by-step lifecycle of an RFQ and maps each Python module to the exact `.md` prompt file it invokes.

```mermaid
sequenceDiagram
    autonumber
    actor Customer as Customer / General Contractor
    participant Classifier as classifier/classifier.py
    participant PageClass as extraction/page_classifier.py
    participant Extractor as new_app/fanout_router.py
    participant Rescue as extraction/dimension_rescue.py
    participant Reconciler as extraction/unit_reconciler.py
    participant Teams as listener/teams_worker.py

    Note over Customer,Classifier: STAGE 1: EMAIL INGESTION (~2s)
    Customer->>Classifier: Sends RFQ Email + Drawings
    Classifier->>Classifier: Calls load_prompt("1.classifier_pass1_system.md")<br/>(Is this spam or real project lead?)
    Classifier->>Classifier: Calls load_prompt("2.classifier_pass2_system.md")<br/>(Matches database candidates & builds summary)

    Note over Classifier,Extractor: STAGE 2: DRAWING EXTRACTION (~45-60m)
    Classifier->>PageClass: Dispatches 100-page PDF
    PageClass->>PageClass: Calls load_prompt("5.page_classifier.md")<br/>(Finds which pages contain glass floor/skylights)
    
    PageClass->>Extractor: Sends filtered relevant pages
    Extractor->>Extractor: Calls load_prompt("6.extraction.md")<br/>(Extracts glass elements, framing, and callouts)
    
    opt If hand-lettered blueprint text is hard to read
        Extractor->>Rescue: Sends high-DPI zoomed crops
        Rescue->>Rescue: Calls load_prompt("7.dimension_rescue.md")<br/>(Rescues dimensions using blueprint font guide)
    end

    Extractor->>Reconciler: Sends raw units from all sheets
    Reconciler->>Reconciler: Calls load_prompt("8.unit_reconciler.md")<br/>(Merges duplicate units across floor plans & sections)

    Note over Teams: STAGE 3: TEAMS COLLABORATION (Independent)
    Teams->>Teams: Chat message -> load_prompt("3.teams_chat.md")
    Teams->>Teams: Meeting ends -> load_prompt("4.teams_meeting.md")
```
