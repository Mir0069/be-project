# 1. High-Level Pipeline Flow

This diagram illustrates the end-to-end flow of an incoming email from the Microsoft 365 webhook, through the AI triage engine, the drawing extraction pipeline, and finally to the backend database and user interface.

```mermaid
flowchart TD
    subgraph EmailIngestion ["1. Email Ingestion & Triage (Fast ~2s)"]
        A["Incoming Outlook RFQ Email + Drawings"] --> B["Azure Service Bus Queue ('leads')"]
        B --> C["Email Worker (listener/worker.py)"]
        C --> D["Pass 1 AI Classifier\n(1.classifier_pass1_system.md)"]
        D --> E["Address & Domain Graph Matcher\n(classifier/graph_matcher.py)"]
        E --> F["Pass 2 AI Project Matcher\n(2.classifier_pass2_system.md)"]
        F --> G["Phase 1 Summary Generated\n(Saved to email.aiAnalysis)"]
    end

    subgraph UserAction ["2. Sales Manager Review"]
        G --> H["Sales Manager Opportunity / Inbox View"]
        H --> I["Sales Manager Clicks 'Accept & Process Proposal'"]
    end

    subgraph DrawingPipeline ["3. CAD Drawing Extraction Pipeline (~45-60m)"]
        I --> J["Stage 0 Worker (listener/extraction_worker.py)"]
        J --> K["200 DPI Page Renderer (fitz)"]
        K --> L["Visual Page Classifier\n(5.page_classifier.md)"]
        L --> M["CAD Vision Extractor\n(6.extraction.md)"]
        M --> N["Tile Dimension Rescue\n(7.dimension_rescue.md)"]
        N --> O["Multi-Sheet Unit Reconciler\n(8.unit_reconciler.md)"]
    end

    subgraph FinalEnrichment ["4. Technical Summary Synthesis (~1ms)"]
        O --> P["Summary & Reasoning Enricher\n(extraction/summary_enricher.py)"]
        G -.-> P
        P --> Q["Phase 2 Enriched Summary & Reasoning\n(Saved to project.aiAnalysis)"]
        Q --> R["Estimator Workspace & AI Insight Dashboard"]
    end
```
