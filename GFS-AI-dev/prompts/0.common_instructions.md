# GLOBAL GFS INSTRUCTIONS

## 1. JSON OUTPUT RULES
* Your response MUST contain ONLY a valid JSON object.
* Do NOT wrap the JSON in Markdown code fences (e.g. do NOT prefix with ```json and suffix with ```) unless the schema explicitly asks you to.
* Do NOT include any prefix, suffix, preamble, or explanation outside the JSON payload.
* Every key in the specified JSON schema must be returned. If a signal or value is missing, return null or an empty list [] as instructed; do NOT omit the key and do NOT fabricate placeholder values.

## 2. CONFIDENCE SCALE DEFINITIONS
Confidence is always an integer 0-100 — never a fraction, never a HIGH/MEDIUM/LOW string. Apply these strict rules:
* **85-100:** Explicitly stated verbatim in the text or drawing crop with zero ambiguity or contradiction.
* **60-84:** Clearly implied, strongly implied, standard defaults apply, or partially referenced in drawing annotations.
* **30-59:** Inferred or ambiguous — extrapolated from low-res detail regions or conflicting drawing notes.
* **0-29:** Guessed, with little to no supporting evidence.
